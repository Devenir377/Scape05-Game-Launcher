**Overview**
This is the Scape05 launcher, a launcher designed to easily download, verify, and launch the latest Scape05 client. This introduces a streamlined approach for fetching remote properties and game files without requiring to manually maintain any folder structure or settings.

### **Highlights**

**Automatic Fetching of game files**

- The Updater downloads the latest game client and additional required libraries from server-defined location.
- Verified via CRC checks and revision files to ensure you have the correct, uncorrupted version.
- All files are stored in a dedicated cache directory (~/.scape1/).

**Cross-Platform**

- It runs on Windows, macOS, and Linux, as long as you have a compatible JRE (Java 8+).


**Getting Started**

1. Grab the Updater .jar from releases.
2. Double-click or run via java -jar Scape05.jar.
3. The Updater will create a ~/.scape1/ folder in the home directory and begin loading the client automatically.
4. Once verification is done, the Updater launches the latest Scape05 client.
